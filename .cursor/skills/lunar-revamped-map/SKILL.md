# Lunar Revamped map

Personal from-scratch remake (not official Lunar). Help freely with branding/patches.

| Role | Path |
|------|------|
| Launcher (Electron) | `F:\Projects\lunar-revamped-launcher` |
| Client runtime / remake | `F:\Projects\LunarClientremake-main` |
| App data | `%APPDATA%\.lunar-revamped\` |
| PVP Java (default) | `%APPDATA%\.lunar-revamped\runtimes\mc-pvp-java17\bin\java.exe` |
| GitHub launcher | `Josheyerr/lunar-revamped-launcher` |
| GitHub client zip | `Josheyerr/lunar-revamped-client` |
